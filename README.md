The "Webmail Bulk Cleaner" is a robust, single-file PHP application designed to streamline the management of cluttered email inboxes. By leveraging the PHP IMAP extension, it connects directly to mail servers—supporting both IMAP and POP3 protocols with SSL or TLS encryption—to search for and mass-delete emails based on user-defined criteria.

The application features a responsive, professional interface built with Bootstrap 5. The workflow is divided into three clear steps: configuring connection settings, defining filter criteria, and executing actions. For the connection, users provide their mail server host, port, credentials, and preferred encryption method. The filtering stage offers high precision; users can specify a date range, target a specific sender address or all senders, and include optional subject keywords to isolate specific types of messages.

A critical component of the app is its safety mechanism. The "Test Mode (Dry Run)" is enabled by default. In this state, the application simulates the search process and returns a count of matching emails without altering the mailbox. This prevents accidental data loss and allows users to refine their search parameters. Once the user verifies the results, they can uncheck the dry run option to permanently delete the found emails.

The UI includes dynamic JavaScript interactions, such as toggling the specific sender field based on selection, and uses Bootstrap alerts to communicate success or errors. Additionally, a "Session Results" card visually displays the number of emails found and deleted. With input sanitization and error handling built-in, the Webmail Bulk Cleaner provides a secure and effective solution for bulk email maintenance, ideal for removing archives of newsletters, spam, or outdated correspondence.
